### 📋 **Requirements**

- **A hosting platform** (Heroku / Render / Katabump / VPS)
- **Node.js** (check `package.json` for the exact version)
- **A valid Session ID** (generate it using the button above)

### ⚙️ **Setup**

```bash
git clone https://github.com/popkidultra/POPKID-BOT
cd POPKID-BOT
npm install
npm start
```
